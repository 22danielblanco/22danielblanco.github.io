# Daniel Blanco de Miguel · Portfolio v0.6

Portfolio bilingüe con doce proyectos y prioridad a la salud digital. Cada ficha incluye funciones, tecnologías, decisiones de ingeniería y un diagrama interactivo. Selecciona un componente para consultar qué recibe y qué entrega. Si el navegador carece de WebGL, el diagrama se muestra en dos dimensiones.

## Ejecutar

Con Node 22.12 o posterior, ejecuta `npm ci` y `npm run dev`. Para comprobar la versión de producción, ejecuta `npm run build` y `npm run preview`.

## Editar

Las fichas, las traducciones y las conexiones están en `src/projects.json`. Las imágenes y el vídeo están en `public/projects/`. La galería de Linfochat queda pendiente de material original. Biblioverse incluye el mapa técnico de su entrega. Las imágenes de AVI-MAMA proceden de una versión anterior a la revisión de arquitectura.

Consulta PUBLISH_GITHUB.md para actualizar el repositorio existente.
